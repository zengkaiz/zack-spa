# 产品需求文档 (PRD) - 游戏列表页

## 一、产品概述

### 1.1 需求背景
为 Web3 SPA 项目增加游戏展示模块，提供游戏浏览、搜索和分页功能，增强产品的娱乐性和用户粘性。

### 1.2 目标用户
- Web3 应用用户
- 游戏爱好者
- 开发者和测试人员

### 1.3 产品目标
- 提供流畅的游戏列表浏览体验
- 支持高效的分页导航
- 采用绿色主题，营造清新、活力的视觉氛围

---

## 二、功能需求

### 2.1 核心功能

#### 功能 1: 游戏列表展示
**优先级**: P0 (必须)

**功能描述**:
- 以卡片形式展示游戏列表
- 每个游戏卡片包含：
  - 游戏封面图
  - 游戏名称
  - 游戏类型/标签
  - 简短描述
  - 评分 (5星制)
  - 在线人数

**验收标准**:
- [ ] 卡片布局响应式适配（PC：4列，平板：2列，手机：1列）
- [ ] 卡片具有 hover 交互效果
- [ ] 图片加载失败时显示占位图
- [ ] 数据加载中显示骨架屏

#### 功能 2: 分页导航
**优先级**: P0 (必须)

**功能描述**:
- 支持页码切换
- 显示当前页/总页数
- 提供"上一页"、"下一页"按钮
- 支持快速跳转到指定页

**验收标准**:
- [ ] 每页显示 12 个游戏
- [ ] 页码按钮支持点击切换
- [ ] 当前页高亮显示
- [ ] 首页时"上一页"禁用，末页时"下一页"禁用
- [ ] 跳转输入框仅接受有效页码

#### 功能 3: 筛选与搜索 (可选)
**优先级**: P1 (重要)

**功能描述**:
- 按游戏类型筛选
- 关键词搜索

**验收标准**:
- [ ] 筛选条件变更时重置到第 1 页
- [ ] 搜索支持实时过滤或防抖搜索

- 页码按钮: hover 时背景变绿色
- 当前页: 绿色背景 + 白色文字
- 禁用状态: 灰色 + 不可点击

## 四、技术实现

### 4.1 技术栈
- **框架**: React 19 + TypeScript
- **路由**: React Router DOM v7
- **样式**: TailwindCSS 4
- **状态管理**: Jotai (如需要)
- **数据**: Mock 数据（本地 JSON）

### 4.2 文件结构
```
src/
├── pages/
│   └── GameList.tsx           # 游戏列表页面
├── components/
│   ├── GameCard.tsx           # 游戏卡片组件
│   ├── Pagination.tsx         # 分页组件
│   └── GameFilter.tsx         # 筛选组件（可选）
├── data/
│   └── mockGames.ts           # Mock 游戏数据
└── routes/
    └── index.tsx              # 路由配置（新增 /games 路由）
```

### 4.3 路由配置
```typescript
{
  path: 'games',
  element: (
    <Suspense fallback={<Loading />}>
      <GameList />
    </Suspense>
  ),
}
```

### 4.4 数据结构
```typescript
interface Game {
  id: string;
  name: string;
  coverUrl: string;
  category: string;
  description: string;
  rating: number; // 0-5
  playersOnline: number;
  tags: string[];
}
```
